Политика конфиденциальности

Приложение «AI agent — помощник студента». Действует с 9 ноября 2026 г.

Кто пользуется

Приложение личное: им пользуется только его владелец. Других пользователей, регистрации и рекламы нет.

Какие данные Google используются

  • Файлы и папки в Google Диске владельца, которые создаёт само приложение: папка «Умный Помощник Студента» с резервными копиями и файлами учебной библиотеки (названия, расположение, ссылки на файлы).
  • Имя и адрес аккаунта Google, а также занятое место на Диске — чтобы показать владельцу, к какому Диску подключено приложение.

Зачем

  • Сохранять резервные копии данных приложения и проверять, что их можно восстановить.
  • Раскладывать учебные файлы владельца по папкам предметов и занятий.

Чего приложение не делает

  • Не передаёт и не продаёт данные, полученные от Google, третьим лицам.
  • Не использует их для рекламы и для обучения моделей искусственного интеллекта, не отправляет их во внешние нейросетевые сервисы.
  • Не трогает файлы Диска вне своей папки.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Хранение и удаление

Ключ доступа к Диску хранится только на личном сервере владельца, закрытом от интернета. Отозвать доступ можно в любой момент на странице myaccount.google.com/permissions; файлы в папке приложения остаются на Диске владельца, и он может удалить их сам.

In English

AI agent is a personal study assistant used by its owner only. It accesses the owner's Google Drive only to store and verify backups of its own data and to organize the owner's study files in a folder the app creates («Умный Помощник Студента»); it also reads the account name, email and storage usage to show which Drive is connected. Data obtained from Google APIs is not shared or sold, not used for advertising, not sent to external AI services and not used to train AI models. Use of such data complies with the Google API Services User Data Policy, including the Limited Use requirements. The access token is stored only on the owner's private server. Access can be revoked at any time at myaccount.google.com/permissions.
